# Palette's Journal - Critical UX & Accessibility Learnings

## 2026-08-22 - Header Navigation & Profile Avatar Integration
**Learning:** Profile navigation in top headers can become redundant when included in both horizontal primary navigation bars and user avatar quick links. Standardizing navigation by keeping header actions dedicated to account avatar/initials icons improves clarity and avoids redundant focus stops for keyboard navigation.
**Action:** Remove redundant "Profile" nav item from navigation arrays when a top-level user avatar icon link exists in the header.
